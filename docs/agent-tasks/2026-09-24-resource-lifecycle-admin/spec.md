# 视频资源生命周期、后台用户与 RBAC 规格

## 目标

在业务平台与评测平台各自独立存储资源的前提下，为视频建立可追踪、可重试的生命周期；保留 JSON 解析数据用于对比与校验；在业务后台增加管理员认证、RBAC、球员资产和视频/解析任务管理。

## 已确认需求

- 评测平台主动上传的视频、Run 与资源不得和业务平台混存。
- “仅删除资源”删除本地及远程视频，保留记录、配置、指标和 JSON。
- “删除全部数据”删除该视频记录、JSON、复核数据和关联资源；不得级联删除球馆、球员或比赛。
- 自动保留期从视频上传成功时间起计算，默认 7 天；只删除视频，JSON 和记录保留。
- 自动清理开关默认关闭；由业务后台统一配置，开启后每天执行，覆盖两个平台。
- 存储供应商暂不确定。数据库必须记录后端类型、位置、对象键、哈希、大小、上传时间和删除状态。
- 只有平台管理员和球馆管理员可以登录后台；球员只是业务资产，没有登录账号。
- 平台管理员具有全局权限；球馆管理员仅能操作所属球馆。
- 球馆管理员可管理球员、视频、解析任务并执行“仅删除资源”；“删除全部数据”只允许平台管理员。
- 首版使用账号密码；未来保留网站微信扫码登录扩展。本地未来可模拟微信身份，测试/生产再接真实微信。
- 默认平台管理员只在系统不存在平台管理员时由环境变量初始化，不写死密码，并要求首次登录修改密码。
- 各环境使用独立数据库连接和独立密钥。

## 当前事实

- 业务库已有 `business.users`、球馆、比赛、参与者、分析任务和场馆成员关系；`business.users` 继续作为球员资产，不作为后台登录身份。
- 业务端已有 `SessionRecordingStore`、远程 GPU 客户端和 operator API，但没有网站会话认证，也没有资源账本。
- GPU 全视频任务的 `DELETE /api/v1/jobs/{job_id}` 目前只取消任务，不删除输入或产物。
- GPU 流式会话已有目录 TTL 清理，但目前按终态更新时间删除整个目录，会连 JSON 一起删，且默认 72 小时；这不符合新规则。
- 评测平台按内容哈希复用输入视频，并把下载产物路径放在 Run JSON 中；没有共享资源引用和逐位置删除状态。
- 评测平台已有四个未提交文件实现数据库 Run 删除，尚未处理本地/远程物理资源。

## 范围

### 包含

- 两个平台的资源表、物理位置表、删除状态与审计。
- GPU 主机的“仅删视频”和“删除全部任务数据”能力。
- 评测平台两种删除动作及失败重试。
- 业务后台账号密码登录、会话、固定双角色 RBAC 和球馆范围。
- 球员资产管理、视频上传/关联、手动触发解析、资源删除。
- 业务后台集中配置 7 天视频清理；单实例日常清理 worker。
- 环境配置、迁移、API、页面、测试和运维文档。

### 不包含

- 小程序登录或球员网站账号。
- 本轮接入真实微信开放平台。
- 选择或接入具体对象存储供应商。
- 自动删除 JSON、评测基线、球馆、比赛或球员。
- 部署、执行生产迁移、删除真实数据、推送或发布。

## 安全与数据边界

- 密码使用标准库 `scrypt`、随机盐和常量时间比较；会话令牌只在浏览器保存 HttpOnly/Secure/SameSite Cookie，数据库只保存令牌摘要。
- 修改类 API 校验登录、角色、球馆范围和请求来源；所有删除与权限变更写入现有审计表。
- 运行中任务不可删除；基线引用的评测 Run 不可“删除全部数据”。
- 删除采用幂等状态机。只有所有目标位置均确认删除后才报告完成；部分失败保留记录并可重试。
- 路径必须由服务端资源账本解析并限制在配置根目录内，客户端不得提交任意磁盘路径。
- 自动清理只选择 `media_type` 为视频、上传时间达到阈值且任务已结束的资源位置。

## 验收标准

- **AC-01**：评测历史可执行“仅删除资源”，本地和已登记远程视频被删，Run 与 JSON 仍可用于比较。
- **AC-02**：平台管理员可对评测 Run 执行“删除全部数据”；成功后 Run、JSON、复核数据和资源记录不可再访问。
- **AC-03**：任一物理位置删除失败时，API 返回未完全完成并保存失败位置；重试不会重复破坏已完成位置。
- **AC-04**：自动清理默认关闭；开启后每天按上传成功时间清理超过 7 天的视频，保留 JSON、Run、分析任务和业务关系。
- **AC-05**：首次启动可从环境变量创建唯一平台管理员；没有环境密码或已有平台管理员时不创建；首次登录必须改密。
- **AC-06**：平台管理员拥有全局权限；球馆管理员只能管理授权球馆，不能删除全部数据、修改全局设置或管理平台管理员。
- **AC-07**：业务后台可创建/停用球馆管理员，可新增/编辑球员资产并建立球馆归属；球员不能登录。
- **AC-08**：管理员可上传业务视频、关联球馆/球员/比赛（允许未关联比赛）、查看存储状态并手动触发解析。
- **AC-09**：业务资源、评测资源和各环境数据库保持隔离；资源标识不依赖公开 URL。
- **AC-10**：登录、管理员变更、解析触发、保留策略变更和两类删除均有审计记录。
- **AC-11**：现有业务记录、评测 Run 和旧 GPU 会话保持可读；未回填的旧资源不会被自动清理。

## 开放项

- 真实微信网站扫码登录、对象存储供应商和跨地域复制在后续任务中确定。
- 生产清理时间默认计划为 `Asia/Shanghai` 每日 03:00，部署前可通过配置调整。
